# Prosto.

Публичный сайт Prosto. с продуктами, ссылками на скачивание и блогом.

[Открыть сайт](https://prostodot.github.io/)

## Локальный запуск

Требуются Node.js 24 и npm.

```sh
npm ci
npm run dev
```

Команда `npm test` собирает сайт в `dist/` и проверяет основные переходы между страницами.

## Продукты и публикации

- Страница продукта создаётся из Markdown-файла в `src/content/products/`. Имя файла определяет адрес страницы. В `links` добавляйте действующие ссылки на веб-версию, установщики или инструкции. Первая ссылка отображается как основная.
- Публикация создаётся из Markdown-файла в `src/content/blog/`. Укажите `title`, `description` и дату `published` в формате `'YYYY-MM-DD'`. В `products` можно перечислить имена файлов связанных продуктов без расширения. Записи без этого поля появятся в общей ленте.

Пуш в `main` запускает проверку и публикацию на GitHub Pages.
